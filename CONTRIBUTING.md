Thank you for helping improve this Microsoft Intune learning repository.

## ✅ Good Contributions

- Corrections aligned with current Microsoft Learn documentation
- New troubleshooting cases with reproducible evidence
- Improvements to PowerShell error handling or safety
- Lab validation steps and screenshots with sensitive data removed
- Accessibility, formatting and navigation improvements

## 📝 Documentation Style

- Use clear English and complete sentences.
- Add an icon to major headings where useful.
- Keep product names and portal paths accurate.
- Link to primary Microsoft documentation.
- Distinguish recommendations from Microsoft requirements.
- Add a header, navigation links and footer to new learning modules.
- Never include tenant IDs, user details, access tokens or real corporate data.

## 🛠️ PowerShell Standards

- Use `#requires` when appropriate.
- Include comment-based help.
- Validate parameters.
- Handle expected errors.
- Avoid destructive behaviour by default.
- Do not collect secrets.
- Explain required permissions.

## 🔄 Contribution Workflow

1. Fork the repository.
2. Create a focused branch.
3. Make and test the change.
4. Update related navigation links.
5. Submit a pull request with purpose, testing and references.

## ⚖️ Content Rules

Do not submit copyrighted training material, exam dumps, credentials, customer data or proprietary corporate procedures.
