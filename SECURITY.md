## Reporting a Security Concern

Do not publish credentials, tenant information, private device data or exploitable security details in a public issue.

For a concern involving repository scripts or documentation:

1. Open a private security advisory through GitHub Security where available.
2. Describe the affected file and behaviour.
3. Include safe reproduction steps.
4. Explain potential impact.
5. Remove tokens, usernames, tenant IDs, serial numbers and corporate data.

## Supported Content

The latest content on the default branch is maintained. Educational examples should always be validated in a non-production environment.

## Script Safety

Repository scripts are provided for learning and diagnostics. Administrators must review code, permissions, collected data and organisational policy before execution.
